# pd-security

Сервис защиты персональных данных перед отправкой текста в LLM. Маскирует ПД, помнит соответствие
по `payload_id`, умеет демаскировать.

## Контракт

`POST /process` с `{"payload": "...", "payload_id": "..."}` -> `{"result": "..."}`.

- Первый запрос с новым `payload_id`: `payload` — исходная строка, возвращается маска.
- Второй запрос с тем же `payload_id`: `payload` — ранее выданная маска, возвращается исходник.
- Тот же ID + тот же исходник -> та же маска (ретрай).
- Тот же ID + посторонний payload -> 409.
- `GET /health` -> живость.

## Стек

Java 21 LTS, Spring Boot 4.0.x (`spring-boot-starter-webmvc`), Maven, Tomcat с виртуальными потоками.
Состояние — in-memory в одной JVM, без внешних компонентов на оцениваемом пути.

## Сборка и запуск

```bash
mvn test
mvn spring-boot:run
```

## Настройка систем

Скопируйте `config/systems.example.yaml` в `config/systems.yaml` и добавьте систему, указав её идентификатор и ссылку на хэш API-ключа.
Поля `enabled`, `detect_types` и `mask_types` управляют доступом, обнаружением и маскированием данных.
Поля `demask`, `strategy` и `combo_rules` задают восстановление, способ замены и условия совместной обработки.
Сохраните корректный файл и перезапустите сервис: при ошибке конфигурации сервис не стартует и сообщает причину.
Новые правила маскирования применяются к новым сессиям, а отключение доступа или демаскирования — также к существующим после загрузки конфигурации.

## Структура

```
src/main/java/ru/alfagen/pdsecurity/
  api/        HTTP-контракты и обработка ошибок
  security/   аутентификация потребительских систем
  policy/     политики систем, combo-правила
  session/    стор сессий, шифрование, fingerprint
  text/       токенизация, диапазоны, нормализация
  detect/     движок детекции и 17 детекторов
  resolve/    резолвер пересечений
  mask/       стратегии маскирования
  service/    машина состояний /process и потребительский сервис
  observability/ метрики, безопасные логи, счётчик токенов
  admission/  бюджеты приёма
```
