# Критерии приёмки

| Gate | Требуемое свидетельство |
|---|---|
| Чистый проект | Независимая сборка, никаких классов из посторонних репозиториев |
| Контракт | HTTP-тесты схемы и пар, все ветки ретраев |
| Состояние | Атомарность, запрет вытеснения, байтовый бюджет, TTL и tombstone |
| Безопасность | Изоляция систем, секреты, шифрование, безопасные логи и ошибки |
| Все типы | Таблица 17 типов с precision/recall/F1 и разбором ошибок |
| Качество | Локальные gates, 100% round-trip в пределах TTL |
| Большие тексты | Фикстуры на 100k токенов, память и время |
| Производительность | Достигнутые успешные RPS, latency, доля 429, soak |
| Потребительский сценарий | Две системы, combo, reload, изменённый ответ mock LLM |
| Поставка | Проверен именно сдаваемый ZIP, версия сервиса совпадает |

## Качество

- typed precision, recall и F1 >= 0,95 по каждому обязательному типу на однозначной части holdout.
- coverage precision/recall >= 0,95.
- round-trip 100% в пределах TTL.
- не-ПД фрагменты сохраняются дословно.
- все 17 типов имеют реальные тесты.

Не проходит gate — исправлять категории и правила, а не снижать порог и не править разметку.
