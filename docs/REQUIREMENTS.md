# Требования

## Контракт

`POST /process` с `{"payload": "...", "payload_id": "..."}` -> `{"result": "..."}`.

- `payload` — `@NotNull`, строка; пустая строка и пробелы допустимы.
- `payload_id` — `@NotBlank`, строка. Не приводить числа к строкам, не обрезать пробелы.
- Лишние поля игнорируются; дублирующиеся ключи JSON -> 400.
- UTF-8, эмодзи, CRLF, табуляции, кавычки и обратные слеши обязаны проходить round-trip.
- Успех — только `{"result": "..."}` со статусом 200.
- Ошибка — безопасное тело без эха payload.

## Статусы

| Условие | Ответ |
|---|---|
| Валидная операция | 200 |
| Невалидная схема или JSON | 400 |
| Аутентификация / запрет | 401 / 403 |
| Конфликт активного ID | 409 |
| Известное истечение | 410 |
| Превышен лимит тела | 413 |
| Неподдерживаемый Content-Type | 415 |
| Чужой или повреждённый токен | 422 |
| Нет ресурса | 429 + `Retry-After: 1` |
| Отказ обязательного компонента | 503 |

## Категории ПД

17 типов: PERSON, BIRTH_DATE, BIRTH_PLACE, PASSPORT, CITIZENSHIP, PASSPORT_ISSUER,
DEPARTMENT_CODE, PASSPORT_ISSUE_DATE, DRIVER_LICENSE, ADDRESS, EMAIL, PHONE, INN, CARD,
CVV, PIN, CARDHOLDER.

## Метрика

Оценка span-based относительно исходника. Дефолт `/process` — `star` (скрытие значения целиком
с сохранением длины и структурных разделителей). Полнота важнее точности, но без скатывания
в маскирование всего текста.
