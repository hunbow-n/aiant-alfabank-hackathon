# Решения

| Решение | Обоснование |
|---|---|
| Java 21 LTS + Spring Boot 4.0.x | Java 27 не LTS; Boot 3.5 достиг EOL 30.06.2026; 4.0 обкатана десять месяцев |
| `spring-boot-starter-webmvc` | `spring-boot-starter-web` deprecated в Boot 4 |
| Дефолт `/process` — `star` | Простота, предсказуемый размер, отсутствие таблицы токенов |
| Состояние in-memory без Redis | Внешний компонент = новый источник 5xx; пара живёт секунды |
| Стор не вытесняющий | Вытеснение активной пары = провал демаскирования |
| Fingerprint вместо equals | На тексте в 100k токенов `equals` недопустим |
| Эфемерный AES-GCM ключ | Состояние живёт минуты; ротация не нужна |
| LLM не вызывается в `/process` | Реальное проксирование ломает SLA |

## Заимствования из AIAlfa-master

Fingerprint вместо сравнения строк, детекция до критической секции + `putIfAbsent`, `Semaphore`
как лимит ёмкости, два TTL, ленивое вытеснение при `get`, эфемерный AES-GCM ключ, детерминированный
жадный резолвер, однопроходная замена через `StringBuilder`, `@NotNull`/`@NotBlank` на контракте,
`make_zip.sh` с allowlist, `AGENTS.md` как контекст исполнителя.

Чего не берём: единственный детектор EMAIL, 409/500 без изоляции отказов, `{{TYPE_n}}` как
единственную стратегию, выключенное логирование, отсутствие метрик.
