# AGENTS.md — операционная инструкция

## Что это
Сервис защиты персональных данных перед отправкой текста в LLM. Маскирует ПД, помнит соответствие
по `payload_id`, умеет демаскировать.

## Контракт
`POST /process` с `{"payload": "...", "payload_id": "..."}` -> `{"result": "..."}`.
Тот же ID + тот же исходник -> та же маска (ретрай). Тот же ID + ранее выданная маска -> исходник.
Тот же ID + посторонний payload -> 409. `GET /health` -> живость.

## Инварианты
- Детекторы не изменяют вход и возвращают только диапазоны.
- Маскирование — один проход по `StringBuilder` над исходной строкой.
- Итоговые диапазоны не пересекаются.
- Дорогая детекция выполняется до критической секции; публикация состояния атомарна.
- Активная пара не вытесняется под давлением памяти; при исчерпании бюджета — 429.
- Исключение в одном детекторе не проваливает запрос.
- Состояние живёт в памяти и теряется при рестарте — это заявленная граница.

## Безопасность
- НИКОГДА не логировать payload, исходники, маски, значения ПД, расшифрованные данные и ключи.
- Не логировать тело запроса и сырой `payload_id`.
- Ответ об ошибке не содержит payload.
